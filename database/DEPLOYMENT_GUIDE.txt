================================================================================
TROUBLESHOOTING
================================================================================

Q: Schema creation fails with foreign key errors
A: Make sure you're using MariaDB/MySQL 5.7+ and run with FOREIGN_KEY_CHECKS=0

Q: Users can't login
A: Check that permissions_version is 1 and role_uuid is correctly set

Q: Permission checks fail
A: Verify RoleModules table has entries. Run:
   SELECT r.name, m.code, s.code FROM RoleModules rm 
   JOIN Roles r ON rm.role_uuid = r.uuid 
   JOIN Modules m ON rm.module_uuid = m.uuid 
   JOIN Scopes s ON rm.scope_uuid = s.uuid;
